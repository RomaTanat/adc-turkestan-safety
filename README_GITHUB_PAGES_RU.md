# Карта безопасности — АДЦ Туркестан (GitHub Pages)

## Быстрая бесплатная публикация

1. Создайте на GitHub новый **Public** repository с названием `adc-turkestan-safety`.
2. Распакуйте этот ZIP на компьютере. В репозиторий нужно загрузить СОДЕРЖИМОЕ архива, чтобы `index.html` лежал в корне репозитория, а папки `assets/` и `templates/` были рядом с ним.
3. В репозитории откройте **Add file → Upload files**, перетащите `index.html`, `.nojekyll`, папки `assets/`, `templates/` и `README_GITHUB_PAGES_RU.md`, затем нажмите **Commit changes**.
4. Откройте **Settings → Pages**.
5. В **Build and deployment → Source** выберите **Deploy from a branch**.
6. Выберите ветку `main`, папку `/(root)` и нажмите **Save**.
7. Подождите, пока GitHub Pages опубликует сайт; затем нажмите **Visit site** в этом же разделе.

Типичная ссылка проекта: `https://<ВАШ_GITHUB_ЛОГИН>.github.io/adc-turkestan-safety/`.

## Что находится в ZIP

- `index.html` — главная страница сайта.
- `assets/plan_А.jpg`, `assets/plan_Б.jpg`, `assets/plan_В.jpg` — планы блоков.
- `templates/` — примеры CSV и Excel-шаблон.
- `.nojekyll` — отключает обработку Jekyll для статической публикации.

## Важные ограничения

- Для GitHub Free Pages репозиторий должен быть публичным. Файлы, загруженные в репозиторий, будут доступны публично.
- Сайт статический. Записи хранятся в localStorage браузера и не синхронизируются между сотрудниками. Импорт и экспорт файлов работает на стороне браузера; для единой общей базы данных понадобится отдельная серверная интеграция.
- Не размещайте персональные данные, действующие внутренние наряды-допуски или другую конфиденциальную информацию в публичном репозитории/на общедоступной странице.
- Если нужно убрать личный логин из публичной ссылки, стандартный URL GitHub Pages проекта включает логин владельца. Можно использовать GitHub-организацию с нейтральным названием либо отдельный домен.
