ПУБЛИКАЦИЯ «КАРТА БЕЗОПАСНОСТИ — АДЦ ТУРКЕСТАН»

СОДЕРЖИМОЕ
- index.html — главная страница сайта
- assets/ — планы блоков А, Б, В
- templates/ — Excel и CSV-шаблоны для импорта

БЫСТРАЯ ПУБЛИКАЦИЯ НА NETLIFY DROP
1. Откройте https://app.netlify.com/drop
2. Перетащите в окно папку «Публикация_сайта_ТБ» или ZIP с файлами сайта.
3. Сервис выдаст общедоступную ссылку вида https://имя-сайта.netlify.app.
4. Откройте ссылку в новом окне и проверьте отображение планов и разделов.
5. Чтобы адрес не был временным и проектом можно было управлять, войдите/создайте бесплатный аккаунт Netlify и сохраните проект в аккаунте.

АЛЬТЕРНАТИВА: GITHUB PAGES
Загрузите содержимое папки в публичный репозиторий GitHub (index.html должен лежать в корне), затем в Settings → Pages выберите Deploy from a branch, ветку main и папку /(root). Ссылка будет вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
1. Это статический сайт. В текущем коде данные сохраняются в localStorage браузера конкретного устройства. Публикация даст всем сотрудникам доступ к сайту по одной ссылке, но записи, добавленные одним сотрудником, не появятся автоматически у других сотрудников.
2. Для общего журнала с одними и теми же данными нужен backend (например, Supabase или Google Sheets API), авторизация сотрудников и разграничение прав. Не загружайте в публичные таблицы персональные данные, внутренние контакты и чувствительные сведения.
3. Не публикуйте на сайте заполненные журналы, если доступ не защищён авторизацией. Публичный URL доступен всем, кто его знает/найдёт.
4. Импорт Excel использует библиотеку SheetJS через CDN и требует интернета; импорт CSV реализован встроенно.
5. Веб-сайт и электронный журнал не заменяют утверждённые процедуры допуска к опасным работам и официальные формы предприятия.
